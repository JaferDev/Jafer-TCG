## Functional Requirements:


- **Player can start the game**
- **Player can login, register, or play as a guest**
- **Player can select a hand from a selection of character cards**
- **Player can select powerups from a selection of powerup cards**
- **Game keeps track of the score, time played, and the high score**
- **High score will be saved for all players logged in with a score greater than the current high score**
- **Player moves onto a new opponent with new hand after defeating current opponent.**
- **Player moves onto a new opponent with new hand after defeating current opponent**
